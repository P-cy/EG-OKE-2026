## 4. เปรียบเทียบกับทางเลือกอื่น (ทำไมถึงเลือก Contabo)

| ผู้ให้บริการ | สเปกเทียบเท่า Option A | ฿/เดือน | เทียบ |
|---|---|---|---|
| **Contabo** | 17 vCPU / 44 GB รวม | **~1,064** | 1× |
| DigitalOcean | 3 droplets (8vCPU/16GB + 4/8 + 2/4) | ~7,600 | 7× |
| AWS (EC2 + DocumentDB + ElastiCache) | ใกล้เคียง | ~13,000+ | 12× |
| Google Cloud | ใกล้เคียง | ~11,000+ | 10× |
| Vultr / Linode | 3 instances | ~5,300 | 5× |
| **MongoDB Atlas M10** (เฉพาะ DB) | 2 vCPU / 8 GB | ~2,200 | เฉพาะ DB ก็แพงกว่าทั้งระบบแล้ว |

**Contabo คุ้มกว่าเพราะ:** ให้ vCPU/RAM ต่อเงินสูงมาก + traffic 32 TB รวมในราคา + ไม่ขึ้นราคาตอนต่ออายุ

**ข้อแลกเปลี่ยนที่ต้องรู้ (สำคัญ):**
| ข้อเสีย | ผลกระทบกับงานนี้ | วิธีรับมือ |
|---|---|---|
| ไม่มี managed DB / backup อัตโนมัติ | ต้อง setup เอง | มีสคริปต์ให้แล้วใน `05-infrastructure.md` |
| ไม่มี auto-scaling | scale ไม่ได้ระหว่างงาน | over-provision ไว้ตั้งแต่แรก (ทำแล้ว headroom 3-6 เท่า) |
| SLA อ่อนกว่า tier-1 cloud | อาจมี downtime | **นี่คือเหตุผลที่ต้องมี app-2** |
| Provisioning ใช้เวลาหลายชั่วโมง | สั่งเครื่องกลางงานไม่ทัน | สั่งครบทุกเครื่องก่อนงาน ≥ 2 สัปดาห์ |
| Network ไป EU latency สูง | หน่วง 180-250ms | **เลือก datacenter Singapore** (~30-50ms) |

## 5. ทางเลือกลดต้นทุนเพิ่มเติม

| วิธี | ประหยัด | ข้อแลกเปลี่ยน |
|---|---|---|
| ใช้ subdomain ของคณะ | ฿400 | ต้องขออนุมัติ |
| Frontend ไปอยู่ Cloudflare Pages (ฟรี) | ลด load app-1 ~40% | ต้องแยก deploy — **แนะนำอย่างยิ่ง** |
| รูปภาพ IG เก็บบน Cloudflare R2 (ฟรี 10GB) | ฿95/เดือน | R2 free tier ไม่มีค่า egress |
| ปิด app-2 นอกเดือนงาน | ฿266 × 4 = ฿1,064 | ต้อง setup ใหม่ตอนเปิด — เขียน Ansible/script ไว้ |
| ขอ education credit จาก Contabo/DO | อาจฟรี | ลองส่งอีเมลขอ — งานนักศึกษาหลายที่ได้ |
| GitHub Student Pack | DO credit $200 | ใช้แทน ops node ได้ทั้งโปรเจกต์ |

> **ทำ 2 อย่างนี้ก่อนเลย:** (1) สมัคร GitHub Student Developer Pack — ได้ DigitalOcean credit $200
> (2) ย้าย frontend ไป Cloudflare Pages — ฟรี, เร็วกว่า, และลดภาระ app-1 ไปมาก
